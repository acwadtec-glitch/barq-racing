# سباق البرق ⚡

نسخة ويب عربية قابلة للعب من لعبة سباق سيارات:

- اختيار الطريق: الصحراء الذهبية، مدينة النيون، طريق الجبال.
- اختيار السائق: نور، فارس، ليان، زياد.
- اختيار العربية: الصاعقة، النمر، السهم، الكاسر.
- أوفلاين ضد الكمبيوتر.
- لاعبان على نفس الجهاز: اللاعب الأول بالأسهم، والثاني بـ WASD.
- أونلاين عبر غرفة خاصة وكود من 6 خانات باستخدام WebSocket.
- تصميم Responsive يعمل على الكمبيوتر والموبايل مع أزرار لمس.

## التشغيل

يتطلب Node.js 18 أو أحدث.

```bash
npm install
npm start
```

افتح بعد ذلك:

```text
http://localhost:3000
```

## اللعب أونلاين

1. افتح اللعبة من نفس السيرفر.
2. اختار «أونلاين» ثم الطريق والسائق والعربية.
3. اضغط «إنشاء غرفة» وانسخ الكود.
4. ابعت الكود لصاحبك ليدخل من جهاز آخر على نفس رابط السيرفر.
5. كل لاعب يضغط «أنا جاهز» ليبدأ السباق.

للتجربة من جهازين على نفس الشبكة، افتح اللعبة عبر عنوان IP الخاص بالجهاز الذي يشغل السيرفر، مثل:

```text
http://192.168.1.20:3000
```

للاستخدام عبر الإنترنت، يحتاج السيرفر إلى استضافة عامة وWebSocket مفعّل، ويفضل HTTPS/WSS في الإنتاج.

## ملاحظات

هذه نسخة Prototype كاملة قابلة للعب. الرسومات مرسومة داخل Canvas وCSS، لذلك لا تحتاج إلى ملفات صور خارجية. يمكن إضافة حسابات، غرف أكثر من لاعبين، أصوات حقيقية، متجر عربيات، وحفظ نتائج في مرحلة لاحقة.
